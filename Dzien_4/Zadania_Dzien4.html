Moduł 1 — State Machine: wprowadzenie
Ćwiczenie 1 — State Machine: Input Dialog z rozgałęzieniem
Folder: Dzien4_Zadanie1_StateMachine_Wprowadzenie/ · Temat: State Machine + Transitions + pętla

Opis zadania

  1. Użytkownik wpisuje imię przez Input Dialog
  2. Jeśli "Adam" → przypisz nazwisko "Nowak"
  3. Jeśli "Ewa" → przypisz nazwisko "Kowalska"
  4. Inne imię → ponów pytanie (pętla!) z Log Message: "Podane imie nie jest Adam ani Ewa."
  5. Wyświetl pełne imię i nazwisko w Log Message

Stany

StanEntryExitTransitions
State - Init (Initial)Input Dialog → str_imie2Log: "Przechodze przez Exit w State Init"str_imie2 = "Adam" → State Adam; str_imie2 = "Ewa" → State Ewa; inne (Action: Log "Podane imie nie jest Adam ani Ewa.") → State Init (pętla)
State - Adamstr_imie2 = str_imie2 & " Nowak"Log: "Przechodze przez Exit - Adam"(bezwarunkowa) → Final State
State - Ewastr_imie2 = str_imie2 & " Kowalska"Log: "Przechodze przez Exit - Ewa"(bezwarunkowa) → Final State
Final StateLog Message: "Twoja osoba to: " & str_imie2—— (koniec)
Wskazówka: Scope zmiennych — str_imie2 musi być na poziomie StateMachine (nie wewnątrz State). Kolejność Transitions jest ważna — pierwsza spełniona wygrywa. Każdy State ma Entry i Exit. Transition ma opcjonalne pole Action (np. Log Message).

Moduł 2 — Dictionary
Ćwiczenie 2 — Kursy walut NBP → Dictionary
Folder: Dzien4_Zadanie2_Dictionary_Waluty/ · Temat: Table Extraction + Dictionary + dostęp po kluczu

Opis zadania

  1. Otwórz stronę NBP z tabelą kursów walut (tabela A)
  2. Pobierz tabelę kursów (Extract Table Data)
  3. Zapisz tabelę do Waluty.xlsx
  4. Zainicjalizuj Dictionary: dict_waluty = New Dictionary(Of String, String)
  5. W pętli For Each Row: klucz = kod waluty, wartość = kurs
  6. Log Message: "Kurs euro to: " & dict_waluty("1 EUR")
Uwaga: Dictionary MUSI być zainicjalizowane w Assign: New Dictionary(Of String, String) — inaczej NullReferenceException!

Moduł 3 — Rozbudowane State Machine
Ćwiczenie 3 — Rozbudowane State Machine z obsługą błędów
Folder: Dzien4_Zadanie3_Rozbudowane_StateMachine/ · Temat: State Machine + BusinessRuleException + SystemException + Robotivity

Opis zadania

Stwórz State Machine z 4 stanami przetwarzającą transakcje z Excela w Robotivity:

Stany procesu

StanOpisTransitions
State - InitConfig → Dictionary, Kill Process, otwórz Robotivity, zaloguj (Retry Scope)Sukces → Pobierz trans.; SE → Final State
State - Pobierz transakcjęSprawdź TransactionNumber, pobierz DataRowSukces → Procesowanie; Koniec → Final State
State - ProcesowanieWpisz dane do Robotivity, obsłuż BE/SESukces → Pobierz trans.; SE → Init (restart!)
Final StateLog status, Kill Process— (koniec)

Kluczowe elementy

  • BusinessRuleException — dane nienumeryczne → pomiń transakcję (NIE ponawiaj)
  • SystemException — błąd techniczny → restart Init (PONÓW)
  • Czyszczenie BusinessRuleException = Nothing na początku procesowania
  • Dictionary jako Config — wzorzec REFramework
  • Retry Scope wokół logowania — 2 próby, 3s odstęp

Ćwiczenie 5a — Dispatcher
Folder: Dzien4_Zadanie5a_Dispatcher/ · Temat: Try Catch + Add Queue Items do kolejki Orchestratora

Opis zadania

  1. Try Catch wokół Read Range:
    • Try: Read Range Workbook — wczytaj Transactions.xlsx (AddHeaders = True)
    • Catch (Exception): Kill Process "EXCEL" → Delay 2s → ponów Read Range
  2. (Opcja A — Bulk) Bulk Add Queue Items:
    • QueueName: Robotivity_Bulk
    • FolderPath: Robotivity2
  3. (Opcja B — po kolei z referencją) For Each Row → Add Queue Item:
    • QueueType: Robitivity_Single
    • FolderPath: Robotivity2
    • Reference: CashIn & "_" & OnUsCheck
    • ItemInformation: CashIn, OnUsCheck, NotOnUsCheck
  4. Log Message: "Transakcje dodane do kolejki"
Wskazówka: Try Catch wokół Read Range zabezpiecza przed zablokowanym plikiem Excel. Opcja Bulk dodaje wszystko na raz, opcja z pętlą pozwala nadać unikatowe referencje.

Ćwiczenie 5b — REFramework Performer
Folder: Dzien4_Zadanie5b_RoboticEnterpriseFramework_Performer/ · Temat: REFramework + Queue + Robotivity + BusinessRuleException

Co należy skonfigurować

  1. Config.xlsx:
    • Settings: OrchestratorQueueName = 4a_Dispatcher
    • Settings: OrchestratorQueueFolder = Nazwa Folderu w Orchestrator
    • Assets: nazwy assetów (ścieżka do aplikacji)
  2. InitAllApplications.xaml:
    • Get Credential → Username, Password
    • Otwórz Robotivity i zaloguj się
  3. Process.xaml:
    • Wyciągnij dane z in_TransactionItem.SpecificContent
    • Sprawdź .IsNumeric
    • Numeryczne → Type Into + Click Accept
    • Nienumeryczne → Throw New BusinessRuleException("Dane nie sa numeryczne")
  4. CloseAllApplications.xaml: Kill Process "robotivity"
Wskazówka: REFramework automatycznie obsługuje retry, logging, status transakcji i restart po System Exception. Programista edytuje głównie: Process.xaml, InitAllApplications.xaml, Config.xlsx.
